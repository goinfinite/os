- containerBootstrap.go — Container bootstrap orchestration (ContainerBootstrap)

- webServerSetup_test.go — Tests the capacity calculator and the config file updater; asserts the computed caps, the rewritten settings, and untouched non-lsphp settings

- MUST NOT fail container setup when the PHP installation check fails; PHP is optional
