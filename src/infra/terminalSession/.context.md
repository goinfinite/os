Terminal session infrastructure. A terminal multiplexer holds the sessions; tmux is the current implementation and its vocabulary is confined to TerminalMultiplexerClient. Every call runs as the session's run-as user, because root cannot talk to another user's multiplexer socket. The run-as user is nobody by default, or the account's own Linux user.

## Summary

- terminalMultiplexerClient.go — resolves the run-as user and owns every multiplexer command: create, set name, send command, kill, list and attach; also parses session listings and opens the attach PTY
- terminalSessionCmdRepo.go — creates, renames, kills and attaches terminal sessions named os-managed-<16-hex>
- terminalSessionQueryRepo.go — resolves the accounts to read (one by id or all), lists each account's own-user and nobody sessions, then sorts and paginates

## Constraints

- MUST run the multiplexer with the run-as user's credentials and a clean environment (HOME, USER, LOGNAME, SHELL, MISE_DATA_DIR, MISE_CONFIG_DIR, MISE_STATE_DIR, MISE_CACHE_DIR)
- MUST give a run-as user that is not the account its own multiplexer socket per account, so accounts never share a server
- MUST set HOME to /app and point every MISE_* dir at the shared toolchain dir for nobody sessions, since nobody owns the web files and its primary group can write the shared dir
- MUST set HOME to the account's own home and point every MISE_* dir there for own-user sessions, so tools that write under HOME never touch the root-owned app directory
- MUST close the PTY to detach; the multiplexer session must survive
- MUST stop the attach process exactly once, in the order kill, close PTY, wait, so the exit status comes from the kill we sent
- MUST log an attach process that ended without a kill signal
- MUST stay silent on every normal detach
- MUST treat a missing multiplexer server as an empty list, not an error
- MUST keep the session display name in the tmux user option `@os-name`, so it lives and dies with the session and never touches a database
- MUST reject a session name carrying the `|` separator, so a name cannot shift the listing columns
- MUST kill the session when a post-create step fails, so a failed create never leaves a session behind

## Guidance

- SHOULD keep the session name prefix in one place (TerminalSessionNamePrefix)
- SHOULD keep the name option key in one place (terminalMultiplexerNameOption)
- SHOULD skip a malformed list line instead of failing the whole read
- SHOULD add multiplexer commands only on TerminalMultiplexerClient, so a different multiplexer means editing one file
