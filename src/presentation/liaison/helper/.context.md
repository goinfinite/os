Shared helpers for the service liaison layer. Package name: `liaisonHelper`. Holds liaison-only collaborators that multiple liaisons reuse.

## Summary

- serviceAvailability.go — `ServiceAvailabilityInspector` (checks an installed service is running), `ServiceUnavailableError`, and `NewServiceUnavailableResponse`
- operatorContext.go — `ReadOperatorContext`: parses operator identity from untrusted input, defaulting to `sharedHelper.LocalOperatorAccountId`/`LocalOperatorIpAddress`

## Constraints

- MUST NOT import the `liaison` package (keeps the dependency one-directional)
