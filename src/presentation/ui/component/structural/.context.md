Structural components for page layouts: page headings, tab headers, rounded-square buttons, collapsible text, and the port bindings and service installation helpers.

## Summary

- Page headings (pageTitle, pageSubHeading) and tab headers
- Rounded-square buttons (responsibleRoundedSquareButton hides the label below a breakpoint)
- Collapsible section and collapsible text
- serviceNotInstalledWarningForm helper

## Constraints

- MUST use Tailwind CSS for responsive design
- MUST render dialogs with `uiDisplay.Modal` or the `uiDisplay` ConfirmationDialog presets, not hand-rolled markup
- MUST take card containers from `uiStructural.Card`; pageSubHeading renders the card header passed as `HeaderContent`
