Main application layout for authenticated users with sidebar navigation and content area. Also hosts the terminal sessions modal, so a session is reachable from every page.

## Summary

- main.templ — Primary page layout template; hosts the scheduled task completion banner and the terminal sessions modal
- state.js — Main Alpine store: routing, footer refresh, scheduled task status tracking, the completion banner flag and the terminal modal open and close state

## Constraints

- MUST only be accessible to authenticated users
- MUST show user's account information and logout option
- MUST load the sessions modal body once and reuse it, so reopening the modal never disposes a live xterm
- MUST hand the session to focus through pendingTerminalSessionId, so opening the modal can target one session
- MUST wrap the sessions modal in an `x-data` scope, so Alpine binds the modal directives
