<context path="src/presentation/ui/presenter/helper" updated="2026-10-01">

Shared presenter utilities used by more than one UI presenter. Each file holds one helper function and the logic that function needs.

## Summary

- dataTablePaginationSettingsResolver.go — DataTablePaginationSettingsResolver maps the response pagination into the DataTable page number, page size, totals, and sort settings
- readPaginationRequestParams.go — ReadPaginationRequestParams reads the pageNumber, itemsPerPage, sortBy, and sortDirection query params and drops the ones that do not parse. It sets no defaults; the liaison applies the use case default pagination.
- readVirtualHostHostnames.go — ReadVirtualHostHostnames returns the non-alias virtual host hostnames used by install forms, with the primary virtual host first so install forms default to it
- shouldEnableInitialSetup.go — ShouldEnableInitialSetup reports whether the initial setup wizard must run

## Constraints

- MUST be reusable across multiple presenters
