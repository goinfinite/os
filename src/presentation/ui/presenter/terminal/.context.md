Terminal page and layout modal fragment. Renders the session list, the create form and the xterm.js tabs. The browser talks to the terminal WebSocket directly.

## Summary

- presenter.go — page handler and modal fragment handler
- index.templ — page, shared session content and the xterm.js CDN dependencies
- state.js — Alpine terminal component: session list, create, kill, tabs and the attach socket

## Constraints

- MUST load xterm.js and addon-fit from jsDelivr with SRI hashes
- MUST reconnect a dropped socket and show a disconnected state
- MUST keep the modal body content identical to the page content

## Guidance

- SHOULD register the Alpine component through UiToolset.RegisterAlpineState, since the fragment can load more than once
