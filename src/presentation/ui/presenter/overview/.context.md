System overview (dashboard) presenter. Renders system status, hardware specs, uptime, IP address, the resource usage graph, and three data tables: terminal sessions, marketplace items and services.

## Summary

- Dashboard/overview page template with paired cards above and below a full-width services table
- Marketplace and terminal sessions share the first row; system information and resource usage share the last row
- The three tables render through uiStructural.DataTable and refresh their rows from the fragment endpoints
- Terminal sessions tile reads through the terminal session liaison and opens the layout modal through the main store
- Quick access to common operations

## Constraints

- MUST display accurate real-time system information
- MUST scope the terminal sessions tile to the operator account
- MUST wrap each card in a plain `div` that carries its `id`. Add `x-data` to the wrapper when Alpine directives live inside the card, because `uiStructural.Card` accepts no attributes
- MUST render a table the same way on the page and on its refresh fragment, so the swapped `data-ui-data-table` region matches
- MUST seed the table page number, page size, totals and sort from the response pagination, so at first render the client state matches the served rows
- MUST pass the pagination query params through unchanged, because the DataTable and the API both use a 0-based page number
- MUST keep untrusted values out of templ.Raw; use the escaped text cell

## Guidance

- SHOULD build DataTable settings in one Go function per table and call it from both the page templ and the fragment handler
- SHOULD name the refresh window events after the mutation, so a table and its mutators stay in sync
