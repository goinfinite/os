Root of Infinite OS — a self-hosted containerized application platform built in Go with a web dashboard, CLI, and REST API. The application follows clean architecture: domain logic in `src/domain/`, infrastructure in `src/infra/`, and user-facing interfaces in `src/presentation/`.

## Summary

- os.go — Application entry point, delegates to CLI initialization
- src/ — Source code: domain (business logic), infra (infrastructure), presentation (API, CLI, UI)
- go.mod / go.sum — Go module definition and dependency lockfile
- Makefile — Build targets: dev server (air), templ generation, binary compilation
- dev-build.sh — Container development launcher with port-mapping profiles
- Containerfile / Containerfile.test — OCI image definitions for production and test builds
- container/ — Runtime configuration for the container (nginx, supervisord)
- tailwind.config.js — Tailwind CSS configuration targeting UI templ files
- docs/ — Documentation: feature map, development guide, security policy, contributing guide
- CHANGELOG.md — Version history and release notes
- README.md — Project overview, features, and quick-start guide
- TODO.md — Project backlog
- LICENSE.md — Eclipse Public License
- AGENTS.md — Code style book and conventions for humans and agents
- .agents/ — Agent configuration: skills, personas, rules, and sub-agent instructions
- .memory/ — Agent memory: long-term notes, plans, session state, and todos
- opencode.json — opencode project configuration
- .env.example — Environment variable template with documented defaults
- .air.toml — Air hot-reload configuration for development
- bin/ — Compiled application binaries
- logs/ — Runtime application logs
- tmp/ — Temporary build artifacts and workspace cache

## Constraints

- MUST use AGENTS.md as the authoritative code style reference
- MUST read directory-level .context.md files before opening code in that directory
- src/ follows clean architecture: domain depends on nothing else; infra and presentation depend on domain
